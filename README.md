# Charlie Bot\n\nPython Discord bot using discord.py.\n\n## Run\n\n1. Install Python 3.10+.\n2. Run: `pip install -r requirements.txt`\n3. Copy `.env.example` to `.env`.\n4. Put your Discord bot token in `.env`.\n5. Run: `python main.py`\n\nIf you set GUILD_ID, slash commands sync immediately to that server.\n\n## Commands\n\nGeneral: `/ping`, `/serverinfo`, `/userinfo`, `/avatar`, `/help`\n\nModeration: `/clear`, `/kick`, `/ban`, `/timeout`, `/say`\n\nNever commit your real bot token to GitHub.\n
